# Vasilek • букеты-гиганты, Омск

Верстка магазина в оболочке Next.js (App Router). Каталог, корзина, заявка на почту,
данные каталога подключаются из Sanity CMS.

## Запуск

```bash
npm install
cp .env.example .env.local   # заполните SMTP и, если нужно, Sanity
npm run dev                  # http://localhost:3000
```

Без `.env.local` сайт работает: каталог берётся из `lib/products.js`, заявка пишется
в лог сервера и покупателю показывается телефон.

## Структура

```
app/
  style.css                 единственный глобальный файл: :root, html/body, сброс
  layout.js                 html/body, CartProvider, Header, {children}, Footer, корзина, модалка
  page.js                   главная
  catalog/page.js           каталог целиком + page.module.css
  delivery/page.js          оплата, доставка, возврат + page.module.css
  privacy/page.js           политика конфиденциальности + page.module.css
  not-found.js              404
  api/order/route.js        приём заявки и письмо на почту магазина

  styles/ui.module.css      общие примитивы (кнопки, заголовки, секции), импортируются точечно

  sections/                 блоки страниц, у каждого свой *.module.css
    Hero, Featured, Steps, Contacts (+ ContactsHours: подсветка текущего дня)

  components/               переиспользуемые части, у каждой свой *.module.css
    Header                  шапка, бургер-меню, кнопка корзины со суммой
    Footer                  контакты, режим работы, разделы
    Catalog                 фильтр по категориям + группы товаров
    ProductCard             карточка: заглушка-узор или фото, цена, счётчик
    CartDrawer              выезжающая корзина
    OrderModal              модальное окно заявки

  cart/CartProvider.jsx     состояние корзины (useReducer + localStorage), панель и модалка

lib/
  shop.js                   телефон, адрес, часы, карта, цена доставки в одном месте
  products.js               локальная копия каталога (53 позиции, 8 категорий)
  catalog.js                Sanity, а если её нет — локальные данные
  sanity.js                 клиент и GROQ-запрос
  format.js                 рубли и склонения без Intl (одинаково на сервере и клиенте)

sanity/schemas/             схемы CMS: category, product
public/logo.jpg             логотип
```

Правила проекта: только flexbox, css-grid нигде нет; стили каждого блока в своём
`*.module.css`; в глобальном `style.css` только переменные, html/body и сброс.

## Каталог → корзина → заявка

1. `getCatalog()` отдаёт категории и товары (Sanity или локальные данные).
2. `Catalog` фильтрует по категориям, `ProductCard` кладёт позицию в корзину.
3. `CartProvider` считает количество и сумму, хранит корзину в localStorage.
4. `CartDrawer` показывает состав, «Оформить заказ» открывает `OrderModal`.
5. `OrderModal` собирает имя, телефон, способ получения, адрес, дату, время, комментарий
   и согласие на обработку данных, затем POST на `/api/order`.
6. `/api/order` проверяет поля, формирует письмо и отправляет через SMTP на `ORDER_EMAIL_TO`.
   Дальше менеджер звонит покупателю.

## Sanity CMS

Схемы лежат в `sanity/schemas` (см. `sanity/README.md`). Slug категорий должны совпадать
с теми, что ждёт сайт: `giants`, `boxes`, `round`, `b6000`, `b4000`, `b3000`, `b2000`,
`balloons`. Как только в окружении появится `NEXT_PUBLIC_SANITY_PROJECT_ID`, каталог
начнёт приходить из CMS, ревалидация раз в минуту.

## Фотографии букетов

Пока фото нет, карточка рисует узор из полей `shape` (1 розы, 2 гортензии, 3 сборный,
4 сердце, 5 шары) и `hue` (0–360). Как только в Sanity у товара появится картинка,
`ProductCard` сам покажет её через `next/image` вместо заглушки. Для локальных данных
добавьте в объект товара `image: "/photos/имя.jpg"`.

## Перед публикацией

- Телефон, адрес, часы и цену доставки правьте в одном файле: `lib/shop.js`.
- Реквизиты Оператора в `app/privacy/page.js` и блоки с пометкой на жёлтом фоне
  в `app/delivery/page.js` нужно заменить своими.
- Проверьте цену доставки: в исходных данных встречались и 350 ₽, и 300 ₽. Сейчас везде 350 ₽.
- Заполните SMTP в `.env.local`, иначе заявки останутся только в логе сервера.
